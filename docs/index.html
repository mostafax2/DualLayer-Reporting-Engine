The Solution

How DualLayer Works

Every model change flows automatically into MongoDB — where a pre-computed, analytics-ready document waits.

MySQL

Model Changed

Any create(), update(), or delete() — automatically detected by the package.

1
2
Observer

Observer Captures

ModelSyncObserver activates, builds a ModelReference with a deterministic sync_id hash.

Queue

Job Dispatched

ProcessSyncJob dispatched to a dedicated queue — the HTTP response never waits.

3
4
SyncEngine

SyncEngine Processes

Verifies idempotency, fetches fresh data from MySQL, transforms it via Transformer, then writes to MongoDB.

MongoDB

Document Ready

Analytics-optimized document: pre-computed duration_ms, ready has_error, grouped nested fields — zero JOINs needed.

5
6
Analytics API

Fast Dashboard ⚡

Analytics endpoint reads from MongoDB with aggregation pipelines — no JOINs, no TIMESTAMPDIFF, zero impact on MySQL.

Features

Everything You Need — Built In

🔐

Guaranteed Idempotency

Same job dispatched twice? Processed once. sync_id = hash of (model + id + operation + updated_at).

🔄

Automatic Retry

MongoDB goes down? The package retries with exponential backoff: 30s → 90s → 270s, then Dead Letter.

🎛️

Pluggable Transformers

Not just a copy — compute derived fields before writing to MongoDB: duration_ms, size_mb, has_error, and more.

🪝

Lifecycle Hooks

beforeSync to abort the sync when needed, afterSync to clear cache or trigger notifications.

📡

Domain Events

Subscribe to SyncCompleted, SyncFailed, SyncRetried, SyncDead — add alerts or metrics without touching the core.

🏢

Multi-tenant Ready

tenant_id flows through the entire pipeline — from Observer to MongoDB to analytics query — automatically.

🔌

Clean Architecture

Hexagonal Architecture — every component behind an Interface. Switch MongoDB to Elasticsearch with one config line.

📋

Full Audit Trail

dlr_sync_operations table records every operation: status, attempts, errors, timings — for debugging and review.

⚡

Stateless Workers

Workers share zero state — scale horizontally without any coordination. Each worker is fully independent.

Developer Experience

Two Lines Are Enough

Full integration happens in AppServiceProvider — no need to touch any model or controller.

// AppServiceProvider.php — this is all you need public function boot(): void { // User without a custom transformer → uses DefaultTransformer DualReport::observe(User::class); // Order with a custom transformer DualReport::register(Order::class, new OrderTransformer()); // ProcessingTask with transformer + lifecycle hooks DualReport::register(ProcessingTask::class, new TaskTransformer()) ->hooks(new TaskSyncHooks()); }
class TaskTransformer implements TransformerInterface { public function handles(): string { return ProcessingTask::class; } public function collection(): string { return 'processing_tasks'; } public function documentKey(): string { return 'task_id'; } public function sourceKey(): string { return 'id'; } public function transform(array $attr): array { return [ 'task_id' => $attr['id'], 'type' => $attr['type'], 'status' => $attr['status'], // Computed once and stored — never repeated on every query 'duration_ms' => $this->diffMs($attr['started_at'], $attr['completed_at']), 'has_error' => !empty($attr['error_message']), 'file' => [ 'name' => $attr['original_filename'], 'size_mb' => round($attr['file_size'] / 1048576, 2), ], ]; } }
class TaskSyncHooks implements SyncHooksInterface { public function handles(): string { return ProcessingTask::class; } // Before write — can abort the sync by returning false public function beforeSync(string $op, array $doc): bool { // Skip expired tasks that never started processing if ($doc['status'] === 'pending' && $doc['attempts'] === 0) { return !$this->isExpired($doc); } return true; } // After write — clear the tenant stats cache public function afterSync(string $op, array $doc): void { Cache::forget("stats:tenant:{$doc['tenant_id']}"); } }
// EventServiceProvider.php — subscribe to sync lifecycle events protected $listen = [ SyncDead::class => [AlertOpsTeam::class], SyncFailed::class => [LogSyncError::class], ]; // AlertOpsTeam.php public function handle(SyncDead $event): void { Log::channel('slack')->critical('Dead Letter!', [ 'model' => $event->model->modelClass, 'id' => $event->model->modelId, 'attempts' => $event->totalAttempts, 'error' => $event->lastError, ]); }
